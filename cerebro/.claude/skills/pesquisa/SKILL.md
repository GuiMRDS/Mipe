# Pesquisa

1. Entenda o que ele quer saber. Se a pergunta for vaga, faça uma única pergunta para afinar.
2. Faça de 2 a 4 buscas (WebSearch) com termos diferentes; leia (WebFetch) as 2 ou 3 fontes mais confiáveis.
3. Responda no chat em até 5 tópicos curtos, com os links das fontes.
4. Se o resultado for útil para o futuro, salve em `notas/pesquisa-<assunto>.md` com a data e os links.
